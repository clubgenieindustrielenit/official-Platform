Build GI Platform — Official Member & Management Platform for CGI ENIT (Club Génie Industriel de l'ENIT).
Fuses Public Vitrine, Interactive Member Portal (Kanban, Leaderboard, Gamification, Visites, Formations, Opportunities), and "Kinetic Forge" Industrial Tech Edge Admin & Bureau Terminal into an end-to-end organizational platform.

═══ TECH STACK ═══
Frontend Framework: Next.js 16 (App Router, proxy.ts middleware convention), React 19, TypeScript 5
BaaS & Database: Supabase (PostgreSQL, Row Level Security, Auth, SSR Cookies via @supabase/ssr & @supabase/supabase-js)
Design System / Styling: "Kinetic Forge" (Industrial Tech Edge — Dark theme default #000000/#0d0e0e, surface #141515, border #2a2c2c, accent amber #fca311, navy #14213d, Google Font Inter), Tailwind CSS v4, Vanilla CSS variables
UI & Animations: @dnd-kit/core & @dnd-kit/sortable (Kanban drag-and-drop), Recharts (Leaderboard & Admin stats), Lucide React (Icons), Framer Motion (Micro-animations), Next Themes
Email & Auth: Resend API (invitation emails), Supabase Auth SSR with Tokenized Invite System (/invite/[token])
Deployment: Vercel (gi-platform-xi.vercel.app)

═══ SPECIAL GAMIFICATION & POINTS ENGINE ═══

award_profile_completion_points() — Trigger PL/pgSQL sur public.profiles:
  - Photo de profil ajoutée (avatar_url): +5 points
  - CV téléversé (cv_url): +10 points
  - Lien LinkedIn renseigné (linkedin_url): +5 points
  - Section prépa renseignée (prepa_section): +5 points
  - Établissement prépa renseigné (prepa_etablissement): +5 points
  - Rang au concours renseigné (rang_concours): +5 points
  - Total potentiel lors de la complétion initiale du profil: 35 points

award_attendance_points() — Trigger PL/pgSQL sur public.event_registrations:
  - Déclenché lors du passage de attended à true par un administrateur
  - Crédite automatiquement +5 points sur le profil du membre
  - Ajoute une entrée dans public.points_log (reason: "Présence visite : [Entreprise/Titre]")
  - Génère une notification système instantanée pour le membre ("Points de présence crédités 🏭")

Moteur de Liste d'Attente & Notification Automatique:
  - register_to_activity(p_activity_id): Si nombre d'inscrits confirmés >= capacity → statut 'waitlisted' avec position queue_position
  - cancel_registration(p_registration_id): Si une place confirmée est libérée → le premier membre waitlisted passe en status='confirmed' et reçoit une notification automatique: "Une place s'est libérée pour la visite chez [Entreprise]. Votre inscription est désormais confirmée !"

═══ UNIFIED ROLE & PERMISSION SYSTEM (RLS & MIDDLEWARE) ═══

Rôles Canoniques de l'Application (lib/types/roles.ts):
  - 'admin'         : Accès complet au Terminal Admin, gestion globale des membres, projets, invitations et paramètres
  - 'membre_bureau' : Accès aux fonctionnalités de gestion du Bureau, suivi des projets, visites et formations
  - 'membre_actif'  : Accès à l'Espace Membre (/membre), Kanban projets, réservation de visites, leaderboard, opportunités

Helpers de Rôle:
  - isBureauOrAdmin(role) : Retourne true pour 'admin', 'membre_bureau' (et alias hérités 'bureau', 'pole_lead')
  - isAdmin(role)         : Retourne true uniquement pour 'admin'
  - getRoleLabel(role)    : Retourne le libellé propre ("Administrateur", "Membre du Bureau", "Membre Actif")

Middleware & Proxies (proxy.ts & lib/supabase/proxy.ts):
  - Conforme à Next.js 16 App Router (remplace l'ancien middleware.ts)
  - Maintient et rafraîchit automatiquement les cookies de session Supabase Auth
  - Restreint l'accès aux routes /admin et /bureau selon les privilèges de l'utilisateur connecté

═══ DATABASE SCHEMA ═══

public.profiles (Stockage des membres et profils)
  id UUID PK (ref auth.users.id ON DELETE CASCADE), email TEXT NOT NULL, first_name TEXT, last_name TEXT,
  role TEXT DEFAULT 'membre_actif' CHECK (role IN ('admin', 'membre_bureau', 'membre_actif')),
  phone TEXT, classe TEXT CHECK (classe IN ('1AGI1','1AGI2','1AGI3','2AGI1','2AGI2','2AGI3','3AGI')),
  linkedin_url TEXT, prepa_section TEXT CHECK (prepa_section IN ('MP','PC','PT')), prepa_etablissement TEXT,
  rang_concours INT, cv_url TEXT, avatar_url TEXT, statut_membre TEXT CHECK (statut_membre IN ('senior','actif','alumni')),
  statut_membre_verified BOOL DEFAULT false, points_total INT DEFAULT 0, profile_completed_at TIMESTAMPTZ, created_at TIMESTAMPTZ

public.invitations (Système d'invitation tokenisée)
  id UUID PK DEFAULT gen_random_uuid(), email TEXT NOT NULL, role TEXT NOT NULL CHECK (role IN ('membre_actif','membre_bureau')),
  token UUID UNIQUE DEFAULT gen_random_uuid(), status TEXT DEFAULT 'pending' CHECK (status IN ('pending','accepted','expired','cancelled')),
  expires_at TIMESTAMPTZ NOT NULL, created_by UUID (ref auth.users), created_at TIMESTAMPTZ, accepted_at TIMESTAMPTZ

public.poles (Pôles d'activités du CGI ENIT)
  id UUID PK DEFAULT gen_random_uuid(), name TEXT NOT NULL, code TEXT UNIQUE NOT NULL, description TEXT, icon TEXT, color TEXT, lead_id UUID (ref public.profiles)

public.hero_images (Carrousel page d'accueil)
  id UUID PK DEFAULT gen_random_uuid(), image_url TEXT NOT NULL, display_order INT DEFAULT 0, uploaded_by UUID (ref auth.users), created_at TIMESTAMPTZ

public.site_settings (Paramètres globaux du site)
  setting_key TEXT PK, setting_value TEXT NOT NULL, updated_at TIMESTAMPTZ

public.activities (Visites, Formations & Événements)
  id UUID PK DEFAULT gen_random_uuid(), title TEXT NOT NULL, description TEXT, content TEXT, image_url TEXT, cover_image_url TEXT, photo_urls TEXT[],
  category TEXT CHECK (category IN ('Workshop','Hackathon','Visite','Formation','Conférence','Autre')),
  type TEXT DEFAULT 'event' CHECK (type IN ('event','visit','formation')), date_start TIMESTAMPTZ, date_end TIMESTAMPTZ, location TEXT, entreprise TEXT,
  trainer_name TEXT, prerequisites TEXT, google_form_url TEXT, training_material_url TEXT, capacity INT,
  status TEXT DEFAULT 'published' CHECK (status IN ('draft','published','archived','cancelled','done')), created_by UUID (ref auth.users), created_at TIMESTAMPTZ

public.event_registrations (Inscriptions & Présences aux activités)
  id UUID PK DEFAULT gen_random_uuid(), activity_id UUID NOT NULL (ref public.activities ON DELETE CASCADE), user_id UUID NOT NULL (ref public.profiles ON DELETE CASCADE),
  status TEXT DEFAULT 'confirmed' CHECK (status IN ('confirmed','waitlisted','cancelled')), queue_position INT, attended BOOL DEFAULT false, points_awarded BOOL DEFAULT false, created_at TIMESTAMPTZ, UNIQUE(activity_id, user_id)

public.projects (Projets du club)
  id UUID PK DEFAULT gen_random_uuid(), title TEXT NOT NULL, description TEXT, pole_id UUID (ref public.poles), lead_id UUID (ref public.profiles),
  status public.project_status DEFAULT 'planned' CHECK (status IN ('planned','in_progress','done')), deadline DATE, progress INT DEFAULT 0 CHECK (progress >= 0 AND progress <= 100), created_at TIMESTAMPTZ

public.project_members (Membres assignés aux projets)
  id UUID PK DEFAULT gen_random_uuid(), project_id UUID NOT NULL (ref public.projects ON DELETE CASCADE), user_id UUID NOT NULL (ref public.profiles ON DELETE CASCADE), joined_at TIMESTAMPTZ, points_awarded BOOL DEFAULT false, UNIQUE(project_id, user_id)

public.project_tasks (Tâches Kanban du projet)
  id UUID PK DEFAULT gen_random_uuid(), project_id UUID NOT NULL (ref public.projects ON DELETE CASCADE), title TEXT NOT NULL, status public.task_status DEFAULT 'todo' CHECK (status IN ('todo','in_progress','done')), assignee_id UUID (ref public.profiles), created_at TIMESTAMPTZ

public.opportunities (Offres de stages & emploi)
  id UUID PK DEFAULT gen_random_uuid(), title TEXT NOT NULL, company TEXT NOT NULL, type TEXT CHECK (type IN ('stage_pfe','stage_ete','stage_ouvrier','emploi','autre')), location TEXT, description TEXT, requirements TEXT, deadline DATE, contact_email TEXT, apply_url TEXT, is_active BOOL DEFAULT true, created_by UUID (ref public.profiles), created_at TIMESTAMPTZ

public.resources (Centre de documentation & drive)
  id UUID PK DEFAULT gen_random_uuid(), title TEXT NOT NULL, category TEXT, description TEXT, drive_url TEXT, file_url TEXT, created_by UUID (ref public.profiles), created_at TIMESTAMPTZ

public.notifications (Système de notifications membres)
  id UUID PK DEFAULT gen_random_uuid(), user_id UUID NOT NULL (ref public.profiles ON DELETE CASCADE), type TEXT CHECK (type IN ('points','message','système')), title TEXT NOT NULL, message TEXT NOT NULL, link TEXT, read BOOL DEFAULT false, created_at TIMESTAMPTZ

public.points_log (Historique de l'attribution des points)
  id UUID PK DEFAULT gen_random_uuid(), user_id UUID NOT NULL (ref public.profiles ON DELETE CASCADE), amount INT NOT NULL, reason TEXT NOT NULL, related_project_id UUID (ref public.projects), created_at TIMESTAMPTZ
